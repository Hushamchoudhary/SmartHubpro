About Smart Hub

Smart Hub is a single-page learning project made with HTML, CSS and JavaScript. It includes a dashboard, tools, notes, a scientific calculator, theme settings and a local profile.

Important: the demo login/profile is not secure authentication. Do not use a real password or store private information here. A real online account system needs a secure backend.
